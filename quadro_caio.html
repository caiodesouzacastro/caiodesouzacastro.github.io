Sincronizar entre computadores

O quadro é guardado num Gist secreto da sua conta GitHub. Configure uma vez em cada computador e ele abre sempre atualizado.

Como pegar o token (1ª vez só):
  1. Abra github.com/settings/tokens/new
  2. Em Note escreva algo como meu-quadro, escolha uma expiração (ou No expiration).
  3. Marque apenas o escopo gist.
  4. Clique Generate token e copie o código (começa com ghp_).
No 1º computador, deixe em branco — um Gist novo será criado e o ID aparecerá aqui. Nos outros computadores, cole esse mesmo ID (ou só o token, que ele acha o Gist sozinho).
Não conectado.
O token fica salvo só neste navegador (no localStorage deste computador), nunca dentro do arquivo. Trate-o como uma senha; se um PC não for seu, use Desconectar ao terminar. Você pode revogar o token a qualquer momento em GitHub → Settings → Developer settings.
